# Athena Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare Athena's NixOS host and boot services without activation.

**Architecture:** Compose a Linux host from common development Home Manager
modules and Linux system services. Use upstream code-server/Tailscale and one
Codex systemd unit for the documented upstream gap.

**Tech Stack:** Nix flakes, NixOS, Home Manager, systemd, Python unittest.

**Spec:** `docs/superpowers/specs/2026-11-04-athena-design.md`

## Global Constraints

- Preserve unrelated working-tree changes and Gaia behavior.
- Credentials stay outside the repository and Nix store.
- No activation, partitioning, enrollment, or home-server edits.

## Review Focus

- Boot without user login: system units must start at multi-user.target.
- Untrusted LAN: only tailscale0 opens TCP 22/8080; Codex socket is private.
- Runtime credentials: code-server must require its environment file.
- Headless Linux: no Darwin shell plugin, GUI apps, or mail profile.
- Pre-install preparation: hardware template and cross-platform commands must
  state what still needs real-machine validation.
